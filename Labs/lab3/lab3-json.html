Exercise 1: Explore and Understand JSON Structure

JSON organizes data using objects, arrays, and name/value pairs. The provided instructor examples show each of these structures. For example, instructor1.json has a top-level Instructor object, while instructor2a.json contains an Instructors array. instructor3.json places a Course array inside an Instructor object.

Name/value pair
"FirstName": "Jack"
Object
"Instructor": { ... }
Array
"Course": [ ... ]
Nested structure
"Instructor": { "Course": [ ... ] }

In the instructor examples, simple values include text such as an instructor’s first name, last name, and title, plus numeric enrollment values. The collection values are arrays of instructors or courses. The nested structures connect related data—for example, the instructor object contains the course array.

{
  "Instructor": {
    "FirstName": "Jack",
    "LastName": "Zheng",
    "Course": [
      { "Title": "IT6713", "Enrollment": 18 }
    ]
  }
}
