Lab 3: JSON

Exercise 1: JSON Structure Exploration

JSON is organized with objects, arrays, and name/value pairs. The instructor examples include a top-level Instructor object, an Instructors array, and a nested Course array inside an instructor object.

Name/value pair
"FirstName": "Jack"
Object
"Instructor": { ... }
Array
"Course": [ ... ]
Nested structure
"Instructor": { "Course": [ ... ] }

Organization Summary

Simple values include text values such as an instructor name and job title, along with numeric enrollment values. Collections are stored in arrays. Nested objects and arrays group related information together—for example, course information belonging to an instructor.

{
  "Instructor": {
    "FirstName": "Jack",
    "LastName": "Zheng",
    "Title": "Assistant Professor",
    "Course": [
      { "Title": "IT6713", "Enrollment": 18 },
      { "Title": "IT6753", "Enrollment": 22 }
    ]
  }
}
