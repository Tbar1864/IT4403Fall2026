Lab 11: Bootstrap and Responsive UI

Overview

Hands-on practice with Bootstrap 5 for responsive interfaces: the grid system, a column drop layout, a collapsing navbar, a responsive form and a responsive table. Every page has a gold badge in the bottom-right corner that shows the active Bootstrap breakpoint while you resize the window.

Bootstrap 5 breakpoints

A class like col-md-6 applies at its breakpoint and every larger size. Bootstrap is mobile-first: start with the phone layout, then add classes for bigger screens.

BreakpointClass infixMin widthTypical device
Extra smallnone (col-*)<576pxPhones in portrait
Smallsm576pxLarge phones, landscape

Largelg992pxLaptops
Extra largexl1200pxDesktops

Key classes used in this lab

container / row / col
The grid: a container holds rows, and rows hold up to 12 columns.
order-* / offset-*
Rearrange or push columns at a breakpoint without changing the HTML.
navbar-expand-lg
Horizontal menu at 992px and up; hamburger (navbar-toggler + collapse) below.
form-label / form-control / form-select
Full-width, consistently styled labels, inputs and dropdowns.
g-3, mb-3, gap-2, d-grid
Spacing and alignment utilities for gutters, margins and button groups.
table, table-striped, table-bordered
Table styling; the table-responsive wrapper adds sideways scrolling on small screens.
