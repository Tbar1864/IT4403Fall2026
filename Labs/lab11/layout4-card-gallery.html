How this layout works

Instead of giving every card a column class, the row uses row row-cols-1 row-cols-sm-2 row-cols-md-3 row-cols-xl-4 g-4. Each child col automatically gets the right width. h-100 makes every card in a row the same height, and g-4 sets the gutter (gap) between cards.

Screen widthWhat you should see
Below 576px1 card per row.
576px to 767px (sm)2 cards per row.
768px to 1199px (md, lg)3 cards per row.
1200px and up (xl+)4 cards per row.

Test it: drag the browser edge narrower and wider, or open DevTools device mode. The gold badge in the corner shows the active Bootstrap breakpoint.
