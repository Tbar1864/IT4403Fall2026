How this layout works

In the HTML source the order is Main, Sidebar, Extras. Order utilities change the visual order without changing the HTML: Main uses order-1 order-lg-2, Sidebar uses order-3 order-md-2 order-lg-1, and Extras uses order-2 order-md-3. Widths also change: Main is full width until 992px, then col-lg-6.

Screen widthWhat you should see
Below 768pxMain, then Extras, then Sidebar, all stacked.
768px to 991px (md)Main full width on top; Sidebar and Extras side by side below it.
992px and up (lg+)Sidebar on the left, Main in the middle, Extras on the right.

Test it: drag the browser edge narrower and wider, or open DevTools device mode. The gold badge in the corner shows the active Bootstrap breakpoint.
