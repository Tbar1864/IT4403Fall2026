How this layout works

Each box in the first row uses col-12 col-sm-6 col-lg-3: full width on phones, two per row from 576px, and four per row from 992px. The second row uses col-md-4, so the three boxes stack until 768px. The third row uses plain col, which always splits the row evenly.

Screen widthWhat you should see
Below 576px (xs)Row 1: 1 per row. Row 2: stacked. Row 3: 3 side by side.
576px to 767px (sm)Row 1: 2 per row. Row 2: stacked.
768px to 991px (md)Row 1: 2 per row. Row 2: 3 side by side.
992px and up (lg+)Row 1: 4 side by side. Row 2: 3 side by side.

Test it: drag the browser edge narrower and wider, or open DevTools device mode. The gold badge in the corner shows the active Bootstrap breakpoint.
