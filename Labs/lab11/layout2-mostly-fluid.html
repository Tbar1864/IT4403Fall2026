How this layout works

The page sits in a container, which is fluid on phones but has a maximum width at each breakpoint, so on large monitors the layout stays centered with margins. The hero is col-12. The three columns below are col-12 col-md-6 col-lg-4, and the last one is col-md-12 col-lg-4 so it spans the full row on tablets instead of leaving a gap. The compare strip at the bottom uses container-fluid, which is always 100% wide.
