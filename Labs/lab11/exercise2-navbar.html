Exercise 2: Responsive Navigation Menu

The column drop page from Exercise 1b, with a responsive Bootstrap navbar added. Make the window narrower than 992px to see the hamburger menu.

About the navbar (Exercise 2)

The navbar at the top has five menu items: Lab 11 Home, Grid Layouts (a dropdown), Navbar, Form and Table. It uses navbar-expand-lg, so:

  • 992px and wider: the menu items display horizontally.
  • Below 992px: the items collapse behind the hamburger button (navbar-toggler). Tapping it opens the menu (collapse navbar-collapse).

The hamburger needs bootstrap.bundle.min.js, which is loaded at the bottom of the page. sticky-top keeps the navbar visible while scrolling.

Bootstrap's grid is a 12-column system. Each column class says how many of the 12 columns an element uses at a given breakpoint and up. Classes without a breakpoint, such as col-12, apply to every size; classes like col-md-8 take over at 768px and wider.

In this column drop pattern, the widths add up to 12 on desktop (3 + 6 + 3), so all three columns fit. On tablets the first two add up to 12 (4 + 8), so the third column has no room and drops to a new line. On phones every column is col-12, so they all stack.
