What is happening right now

These numbers update as you resize the window or rotate your phone. The cards below change color using only CSS media queries, with no JavaScript, so you can see which rules the browser is applying.

a) Width between 400px and 600px

@media screen and (min-width: 400px)
              and (max-width: 600px) {
  /* styles */
}

Test it: drag the window between 400 and 600 pixels wide.

b) Portrait and width < 640px

@media (orientation: portrait)
   and (max-width: 639px) {
  /* styles */
}

Test it: on a phone, hold it upright. In a browser, make the window narrower than 640px and taller than it is wide.

c) Narrower than 16:9 and width 480px–960px

@media (max-aspect-ratio: 16/9)
   and (min-width: 480px)
   and (max-width: 960px) {
  /* styles */
}

Test it: a tablet, or a window 480–960px wide that isn't a very wide, short strip.

d) Print, or screen width < 480px

@media print,
       screen and (max-width: 479px) {
  /* the same styles for both */
}

Test it: make the window narrower than 480px, or open Print Preview (Ctrl+P / Cmd+P). This card turns red in both cases.

How to read these queries

  • and means every condition must be true. A comma (,) works like or, which is why query d covers both print and small screens with one set of styles.
  • min-width means "this wide or wider" and max-width means "this wide or narrower." Both include the number itself, so "less than 640px" is written max-width: 639px, and "less than 480px" is max-width: 479px.
  • orientation: portrait is true when the viewport is taller than it is wide (or square).
  • aspect-ratio is width ÷ height. 16:9 is about 1.78. "Narrower than 16:9" means a smaller ratio, so it uses max-aspect-ratio: 16/9. A typical 1920×1080 monitor window is wider than that, while a tablet, a phone or a tall window is narrower.
  • Newer browsers also accept range syntax, which reads more naturally: @media (400px <= width <= 600px), (width < 640px) and (aspect-ratio < 16/9).

Testing in Chrome or Edge

  1. Press F12 to open DevTools, then click the device toolbar icon (or press Ctrl+Shift+M).
  2. Pick a device like iPhone 12 Pro or iPad, or choose Responsive and type an exact width and height.
  3. Use the rotate button to switch between portrait and landscape and watch card b.
  4. For card d, press Ctrl+P and look at the print preview.
