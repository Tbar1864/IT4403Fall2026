Objective

Hands-on practice with responsive web design: media queries, fluid grid layouts, and evaluating real websites on a mobile device.

Lab Tasks

  • Task 1: Media Queries Four media query rules, with cards that light up as each rule becomes active: width 400–600px; portrait and narrower than 640px; narrower than 16:9 and 480–960px wide; print or narrower than 480px.
  • Task 2: Fluid Grid Layout (original fixed version) lab10a-fixed.html converted from fixed pixel widths to percentages using target ÷ context = result, so the layout resizes with the window.
  • Task 3: Full Responsive Design (original fixed version) lab10b-fixed.html rebuilt with a fluid grid, a flexible header image and media queries: 4 players per row on desktop, 3 on tablet, 2 on mobile and 1 on small phones.
  • Task 4: Website Evaluation Layout, navigation and readability problems found on weather.gov and cobb.com on a phone, and how responsive design would fix them.

Key Concepts

Viewport meta tag
<meta name="viewport" content="width=device-width, initial-scale=1"> tells phones to use their real width. Without it, media queries for small screens never fire.
Fluid grid
Widths are written as percentages instead of pixels: target ÷ context = result (for example, 200px ÷ 900px = 22.2222%).
Flexible images
img { max-width: 100%; height: auto; } lets images shrink with their column.
Media queries
@media screen and (max-width: 640px) { … } applies extra CSS only when a condition is true, such as screen size, orientation, aspect ratio or print.
Breakpoints
The widths where the layout changes. Here they're 960px (tablet), 640px (mobile) and 420px (small phone).
