Lab Work

Hands-on lab activities, instructions, and supporting resources for the course.

Lab 1: Website Design

This lab focuses on Website Design, Hosting, and Repository Management.

  • Lab 1: Website Design, Hosting, and Repository Management

Lab 2: jQuery

This lab includes practice with jQuery selectors, events, DOM manipulation, CSS changes, visual effects, and interactive applications.

  • Exercise 1: JavaScript and jQuery Comparison
  • Exercise 2: jQuery ready() and Event Handling
  • Exercise 3: jQuery Selectors, DOM, and CSS
  • Exercise 4: Table Selection and Event Handling
  • Exercise 5: jQuery Visual Effects
  • Exercise 6: jQuery Calculator Application
  • Exercise 7: Picture Browser Application

Lab 3: JSON

This lab provides hands-on practice with JSON structure, JSON validation, and reading and displaying JSON data using JavaScript and jQuery.

  • Exercise 1: JSON Structure Exploration
  • Exercise 2: Create and Validate JSON
  • Exercise 3: Read JSON Values
  • Exercise 4: Nested JSON Data
  • Exercise 5: Weather JSON
  • Exercise 6: Movie Information Page

Lab 4: RESTful Web APIs

Retrieve live user, album, and photo data from JSONPlaceholder. Select an album on Page 1 to view its information and photos on Page 2.

  • Lab 4: User, Albums, and Photos
  • Lab 4: Consume a Service Using PHP

Lab 5: Open Library APIs

Retrieve live book data from Open Library using JavaScript fetch(), then display book titles and first publication years.

  • Lab 5: Open Library APIs

Lab 6: AJAX

Use jQuery AJAX methods to load server content and update parts of the page without refreshing the entire page.

  • Activity 1: Modify an Existing AJAX Example
  • Activity 2: AJAX Error Investigation
  • Activity 2: AJAX Error Investigation (Fixed)

Lab 7: AJAX REST & Cross-Origin Requests

Perform AJAX REST requests and handle cross-origin requests.

  • Task 1: Wikipedia Search Suggestions Using AJAX
  • Task 2: ZIP Code Lookup Using AJAX and CORS
  • Task 3: Open Library Book Search Using AJAX

Lab 8: CSS Flexbox and Template

This lab uses CSS Flexbox to lay out data items and Google Books search results, adds buttons that switch between list and grid layouts, and uses Mustache templates to build the book HTML and switch between two views.

  • Exercise 1: Flexbox Item Layout Playground
  • Exercise 1: CodePen version
  • Exercise 2: Google Books in a Flexbox Grid
  • Exercise 3: Switching Flexbox Layouts
  • Exercise 4: Books Grid with a Mustache Template
  • Exercise 5: Layout Buttons with a Mustache Template
  • Exercise 6: Two Mustache Templates, Two Views

Lab 8 (Open Library Version): CSS Flexbox and Template

Exercises 2-6 of Lab 8 rebuilt with the free Open Library search API instead of Google Books. Each page uses CSS Flexbox layouts, layout-switch buttons, and Mustache templates to display live book results.

  • Exercise 2: Open Library Books in a Flexbox Grid
  • Exercise 3: Switching Flexbox Layouts
  • Exercise 4: Books Grid with a Mustache Template
  • Exercise 5: Layout Buttons with a Mustache Template
  • Exercise 6: Two Mustache Templates, Two Views

Lab 9: Data Interaction Enhancements

This lab explores data interaction and details-on-demand UI patterns with the Open Library search API. Task 1 renders paged search results with a Mustache template, and Task 2 turns the scrolling results page into a horizontal slideshow with (current page / total pages) paging.

  • Lab 9 Demo Index (All Patterns)
  • Task 1: Pagination with a Mustache Template
  • Task 2: Horizontal Slideshow with (Current / Total) Paging

Lab 10: Responsive Web Design

This practice lab covers responsive web design: CSS media queries, converting a fixed-width page to a fluid grid, building a full responsive layout for desktop, tablet and mobile, and evaluating real websites on a mobile device.

  • Lab 10 Overview and Key Concepts
  • Task 1: Media Queries
  • Task 2: Fluid Grid Layout (lab10a)
  • Task 3: Full Responsive Design (lab10b)
  • Task 4: Website Evaluation (weather.gov and cobb.com)

Lab 11: Bootstrap and Responsive UI

This lab uses Bootstrap 5 to build responsive interfaces: five grid layouts, a column drop pattern, a navbar that collapses into a hamburger menu, a responsive Bootstrap form, and a striped, bordered table inside a table-responsive wrapper.

  • Lab 11 Overview and Breakpoints
  • Exercise 1a: Five Bootstrap Grid Layouts
  • Exercise 1b: Column Drop Pattern
  • Exercise 2: Responsive Navigation Menu
  • Exercise 3: Responsive Form
  • Exercise 4: Responsive Table
